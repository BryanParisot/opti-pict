# Politique de sécurité

## Versions prises en charge

Seule la dernière version publiée d’Opti Pict reçoit les correctifs de sécurité.

## Signaler une vulnérabilité

N’ouvrez pas de ticket public pour une vulnérabilité non corrigée.

Utilisez la fonctionnalité **Security → Advisories → Report a vulnerability** du dépôt GitHub. Si elle n’est pas disponible, contactez le propriétaire du dépôt en privé avant de publier des détails.

Indiquez si possible :

- la version d’Opti Pict, de WordPress et de PHP ;
- les conditions et étapes minimales de reproduction ;
- l’impact observé ;
- une proposition de correction, si vous en avez une.

N’incluez jamais de clé API réelle, de sauvegarde de base de données ou d’image privée. Révoquez immédiatement toute clé qui aurait été exposée.

Les signalements seront confirmés, évalués et corrigés avant une publication coordonnée lorsque la vulnérabilité est reproductible.
